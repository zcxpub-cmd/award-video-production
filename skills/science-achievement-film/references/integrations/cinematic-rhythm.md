# 摄影质感、镜头提示词与节奏转场

以下为针对科研成果片原创编写的摄影和剪辑操作规则，不含第三方导演库、非商业许可提示词模板或实现代码。源插件仅用于发现本流程需要覆盖的主题；本说明可独立执行。任何风格设定都不能修改科学事实、实拍装置结构、批准的Logo和正式名称。

## 每镜头的摄影决策

1. 在分镜写明观众此刻必须看懂的对象/动作/因果，只允许一个主要信息目标。
2. 明确真实可放相机的位置、与主体距离、机位高度、前景遮挡、视线和焦点；选择焦段服务空间关系，不用“35mm”掩盖机位缺失。
3. 写出主光从哪里来、方向、软硬和主要反光面；金属、玻璃、显示器分别检查高光、透射和可读范围。暗部是否可辨由内容目的决定，不一律提亮。
4. 一个镜头只选一条主要运动：固定、推进、横移、转动或跟随，写明起点、结束位置、时长。结构本身不应因运镜扭曲。
5. 明确保留项：科学几何、标牌、比例、接口数量、液体边界、手部动作、颜色编码。AI无法稳定保留的交给原图、三维几何或后期合成。
6. 生成后同帧对照参考，优先查科学对象，再查塑料反光、纹理漂移、局部过锐、假文字、主体光源矛盾；一次返工只改主要失败变量。

分镜提示词字段：`source_reference / purpose / subject_locks / start_state / action / end_state / camera / light / material / duration / ratio / exclusions / evidence_label`。将这些字段压成一段自然语言；若由参考图约束，明确哪个引用负责结构、哪个负责运动，不能把风格参考当事实来源。

## 节奏图与旁白

在时间线先标开场问题、证据展示、原理解释、结果揭晓和结束落点，再铺旁白实际音频。按听清专名和看懂图示所需时间分配镜头；允许动作间停顿，不能每个镜头等长机械切换。情绪推进可缩短空转段，但不通过加速审定旁白挤时长。

建立 `time_s / narration_phrase / visual_change / audio_event / hold_reason` 节奏表。看画面无声检查视觉因果，再只听声音检查语义和呼吸，最后同步看听检查剪点。遇到赶，先减少同镜头动作或文案密度；遇到拖，先剪没有新增信息的停留，保留科研结果必要阅读时间。

## 转场选择和实际计算

默认硬切用于信息切换；动作匹配/方向匹配连接同一行为；叠化只在时间经过、空间过渡或明确视觉关系需要时使用。声音可先入/后出形成连接，不能把实验声/旁白切断。动画UI里的300–800ms等建议不能直接当电影镜头时长标准。

两段同画幅同帧率、各5秒视频，叠化0.4秒，第二段在4.6秒开始，总时长9.6秒。先用doctor确认 `xfade/acrossfade`，再按实际源格式建立试样；例子假设两源均有音轨：

```sh
ffmpeg -n -i '/project/work/a.mp4' -i '/project/work/b.mp4' \
  -filter_complex '[0:v]fps=25,scale=1920:1080,setsar=1,settb=AVTB,setpts=PTS-STARTPTS[v0];[1:v]fps=25,scale=1920:1080,setsar=1,settb=AVTB,setpts=PTS-STARTPTS[v1];[v0][v1]xfade=transition=fade:duration=0.4:offset=4.6[v];[0:a]aresample=48000,asetpts=PTS-STARTPTS[a0];[1:a]aresample=48000,asetpts=PTS-STARTPTS[a1];[a0][a1]acrossfade=d=0.4[a]' \
  -map '[v]' -map '[a]' -c:v libx264 -pix_fmt yuv420p -c:a aac '/project/work/transition-v01.mp4'
```

这是规范化的独立试样，不用于盲目拉伸正式不同画幅素材。正式画面需要按合同决定补边/裁切。缺音轨时去掉相应音频链，不能照抄不存在的 `[1:a]`。逐帧查叠化两端主体位置、重影和亮度跳变，试听交叉处双声/相消；再核对总时长。失败先查两源实际帧率、时基、宽高和音轨，不能反复试几十种花哨转场掩盖接点问题。
