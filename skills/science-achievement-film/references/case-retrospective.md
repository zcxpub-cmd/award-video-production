# 通用返修案例与复用规则

以下为匿名化、概括性的制作问题，不包含真实项目路径、人员或专有素材。用于预防同类错误，不作为任何新任务已通过的证据。

| 常见问题 | 处理方法 | 验证方式 |
|---|---|---|
| 只换片尾却把全篇重录 | 锁定其他音轨，仅替换受影响完整句段 | 比较继承音频与首尾衔接 |
| 长标题因消除断句被加速 | 保持自然语速，重新生成完整标题句 | 原速试听与实测时长 |
| 专有名词、数字单位拆读 | 建保护词和读音表，区分TTS与屏显文本 | 检查实际分段并逐项听审 |
| 句号处卡顿噪声 | 修复明确异常区间但保留停顿长度 | 波形辅助+原速耳听 |
| 图表标签全部擦除 | 区分宣传字幕与科学信息 | 检查坐标、单位、比例尺、画中画 |
| 装置靠提示词猜结构导致穿模 | 先锁三视图、坐标轴和部件关系 | 多视图/运动全程核对 |
| 为时长剪掉机制关键动作 | 精简文字或延长镜头，保留完整因果 | 输入到输出连续可理解 |
| 静图通过抖动推拉“伪动态” | 稳定适配、适当信息分层或更换真实动态源 | 原速播放检查舒适度 |
| 用放大裁切弥补低清素材 | 优先高清原件、完整视场和单独包装 | 逐字与细节对比原件 |
| 完整装置一直只有生成概念图 | 依据项目证据决定实拍或示意，清楚区分 | 成果本体与来源核对 |
| 素材墙服务启动但无法审看 | 检查浏览器加载、Range播放、备注持久化 | 真浏览器操作并刷新验证 |
| 保存窗口阻塞后反复点按钮 | 读实际窗口和工程，做一次操作再验证 | 状态读回、保存后重开 |
| 导出成功即宣布全面完成 | 文件、解码、播放器、用户接受分层 | 留每层覆盖范围和证据 |
| 只归档成片与工程遗漏程序输入 | 检查运行配置和跨版本继承的源 | 移开原目录后恢复测试 |
| 依据“旧版”文件名直接删档 | 先显式依赖清单与校验，再可恢复隔离 | 保留集hash和工程重建 |

参数如镜头长度、BGM先行时间、章间等待、生成分辨率和章数都应由项目确定。风格示范不自动扩大软件权限、来源授权或付款额度。
