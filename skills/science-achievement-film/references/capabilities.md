# 内置范围与验收依据

“内置”表示本包有实际脚本或独立完整方法，不表示商业软件、模型权重或账号也包含在包内。

| 能力 | 本包提供 | 执行依赖/真实边界 |
|---|---|---|
| 策划/事实/文案/语义分镜 | 完整方法、模板、四层文本与出处 | 智能体结合资料判断；事实需核查 |
| 文档与逐章文稿 | content_tools，DOCX/PPTX/文本提取、DOCX输出 | PDF用pdftotext；复杂公式/版式/动画实际打开 |
| 素材盘点/近重复候选 | filmkit与media_tools | FFmpeg探测/抽帧；语义去重不能仅依赖像素 |
| 可播放审核墙 | 完整build/serve、前端、审核与导出、代理 | 浏览器及FFmpeg；无云托管 |
| OCR/ASR/内容分析 | 精确调用/操作/检查方法内置 | 用户配置OCR/ASR/视频分析软件或服务 |
| 配音/发音/局部修补 | 导演方法、接口配方、任务恢复、音频编排 | TTS模型/声线授权；实际试听 |
| 生成/摄影/节奏/几何 | 方法、提示词与最小HTTP客户端 | 外部生成服务/Blender或FreeCAD |
| 字幕与标题 | 实测时间码→SRT/ASS、独立Title层、烧录 | FFmpeg/libass/字体；复杂原生包装用NLE |
| 剪辑与混音 | 显式recipe、等比拼接、淡入淡出、混音/duck/保时静音 | FFmpeg；无隐式任意滤镜执行 |
| 调色/稳像/复杂后期 | 内置原生软件操作和检查方法 | 实际编辑器及当前可用接口 |
| 分项导出/技术QC | 章节片、流参数、全解码、黑场/冻结候选 | FFmpeg；播放器和声音听审另做 |
| 依赖归档/迁移/清理 | 发现候选、独立复制、哈希、JSON迁移、隔离恢复/审定删除 | 动态依赖人工核查；原生工程重开另验 |
| 公开包准备 | 隐私规则扫描、白名单ZIP、许可和来源 | 人工隐私/授权检查；不自动推送GitHub |

回归使用虚构临时素材和离线服务模拟，不附个人工程/账号/模型。各模块测试位于tests；运行时失败或软件缺失不得伪报整项通过。内容/语义和最终用户接受不由自动脚本赋值。
