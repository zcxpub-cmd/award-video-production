安装并打开完整工作台

解压发行 ZIP 后，macOS 双击「启动影序.command」，Windows 双击「start-yingxu.bat」，Linux 运行「sh start-yingxu.sh」。首次启动在用户目录安装依赖。需要 Python 3.10 或更新版本和网络。

打开已启动的开源工作台。可新建项目、导入素材、编辑时间线、套用提示词模板与导出。

命令行素材审核演示

在下载包根目录打开终端。先运行内置演示，生成一份新的本地素材墙。需要 Python 3.10+、支持字幕滤镜的 FFmpeg 和 FFprobe。

python3 skills/science-achievement-film/scripts/demo_project.py --output "../yingxu-demo"
python3 skills/science-achievement-film/scripts/agent_tools.py launch "../yingxu-demo/wall" --port 8765

Windows 可将 python3 替换成 py -3。成片字幕需要指定本机已安装的中文字体，例如在第一条命令加上 --font "Noto Sans CJK SC"。服务会先打开影序首页。也可以打开 127.0.0.1:8765。

已有素材墙时，可直接把第二条命令中的目录换成现有素材墙目录。
