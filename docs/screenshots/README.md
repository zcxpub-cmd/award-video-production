# 功能截图

截图来自公开版 v1.0.0 的真实本地浏览器界面，不是生成的界面效果图。媒体为自产几何图形和程序动画，用于展示功能，不代表科研成果或某个生成模型的效果。

| 文件 | 展示内容 |
|---|---|
| `01-material-wall-overview.jpg` | 6张素材卡片、来源与AI标记、句子编号、审核统计 |
| `02-material-wall-filter.jpg` | 同时按章节和待审状态筛选，剩1条候选 |
| `03-material-wall-review.jpg` | 6秒视频预览、素材属性和审核入口 |
| `04-material-wall-saved.jpg` | 对应句子、通过状态、备注和已保存反馈 |

审核保存后已刷新页面确认状态与备注保留；播放器读到6秒结束且无解码错误。截图保留原始浏览器画面，没有重绘或合成不存在的控件。截图未包含浏览器账号、桌面、个人路径或真实项目资料。

公开包只收录截图，不收录此次运行目录、媒体白名单和含路径的导出文件。可用内置 `demo_project.py` 创建另一套虚构流程演示；它使用测试图，不与此页六卡片数据完全相同。
