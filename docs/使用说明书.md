# 影序开源版使用说明书

适用于 GitHub 开源版 `v1.1.0` 的源码和工具 ZIP。可在 Windows、Linux 或 macOS 上按本指南配置。开源版的主要入口是 Python 命令、浏览器素材墙和智能体工具。

## 1. 安装与第一次运行

1. 在 [GitHub Releases](https://github.com/zcxpub-cmd/award-video-production/releases/tag/v1.1.0) 下载影序源码工具 ZIP 并解压。也可以克隆仓库。项目、素材、密钥及生成结果放在解压目录之外。
2. 安装 Python 3.10 或更新版本。媒体探测、演示和渲染还需要 `ffmpeg`、`ffprobe`。完整演示需要带 `libx264`、AAC 编码和 `libass` 字幕支持的 FFmpeg，以及本机已安装的中文字体。
3. 将 FFmpeg 的可执行文件目录加入 `PATH`，重新打开终端。检查版本后，从解压目录进入 `skills/science-achievement-film`。

| 平台 | 终端与 Python | FFmpeg 和字体 |
| --- | --- | --- |
| Windows | 使用 PowerShell。运行 `py -3 --version`，再用 `py -3` 执行下面的 Python 命令。如果安装只提供 `python`，使用 `python --version` 检查后改用 `python`。 | 下载适用于 Windows 的 FFmpeg 构建，把包含 `ffmpeg.exe` 和 `ffprobe.exe` 的目录加入用户 `Path`。中文演示可选择已安装的 `Microsoft YaHei`。 |
| Linux | 使用系统终端。运行 `python3 --version`。 | 用发行版的软件包管理器安装 FFmpeg/FFprobe 和中文字体，例如 Noto Sans CJK SC，或指定已有的完整 FFmpeg 构建。 |
| macOS | 使用终端。运行 `python3 --version`。 | 安装具备字幕滤镜的 FFmpeg 构建。中文演示可选择已安装的 `PingFang SC`。 |

[Python 下载](https://www.python.org/downloads/) · [Windows Python 配置](https://docs.python.org/3/using/windows.html) · [FFmpeg 下载](https://ffmpeg.org/download.html)

```text
ffmpeg -version
ffprobe -version
ffmpeg -hide_banner -filters
```

完整演示要能找到 `ass`、`blackdetect` 和 `freezedetect`。下面的示例从 `skills/science-achievement-film` 运行，输出到仓库外一个全新的 `yingxu-demo` 目录。将字体名替换为本机的实际字体。

macOS / Linux：

```bash
python3 scripts/agent_tools.py list
python3 scripts/demo_project.py --output "../../../yingxu-demo" --font "Noto Sans CJK SC"
python3 scripts/material_wall.py serve "../../../yingxu-demo/wall" --port 8765
```

Windows PowerShell：

```powershell
py -3 scripts/agent_tools.py list
py -3 scripts/demo_project.py --output "../../../yingxu-demo" --font "Microsoft YaHei"
py -3 scripts/material_wall.py serve "../../../yingxu-demo/wall" --port 8765
```

若 FFmpeg 未加入 `PATH`，可为 `demo_project.py` 加 `--ffmpeg` 和 `--ffprobe`，分别填写可执行文件的绝对路径。启动素材墙后，在浏览器打开 `http://127.0.0.1:8765/`，播放、审核并保存备注。成片位于演示目录的 `delivery/film.mp4`，其余输出见 `START_HERE.md`。演示使用合成测试画面和声音，运行时无生成服务费用。

## 2. 做自己的工程或接入智能体

从仓库外的新目录开始，准备文稿、镜头清单和素材。把候选素材放进素材墙播放审核，按确定的源文件和时间范围编辑 `edit.json`，然后渲染并检查实际影片。完整命令见 [从零到可审核输出](../skills/science-achievement-film/references/quickstart.md)，字段见 [媒体和剪辑配方](../skills/science-achievement-film/references/local-media-tools.md)。

使用 Codex 时，可在支持插件市场的版本中按 [仓库安装步骤](../README.md#安装与调用) 安装，或加载 `science-achievement-film` Skill。其他能够启动本地进程的智能体宿主，可把 `agent_tools.py list` 注册为工具发现，再用 `invoke inventory`、`invoke check` 或 `invoke probe` 调用。参数通过标准输入传入，结果从标准输出读取。运行脚本的机器要能访问相应的工程或素材路径。以下命令用刚做完的演示目录试一次素材盘点。

macOS / Linux：

```bash
printf '%s\n' '{"source":"../../../yingxu-demo/media"}' | python3 scripts/agent_tools.py invoke inventory
```

Windows PowerShell：

```powershell
'{"source":"../../../yingxu-demo/media"}' | py -3 scripts/agent_tools.py invoke inventory
```

返回 `ok: true` 时可查看 `report`。通用工具入口目前提供三个只读工具。渲染、归档和外部生成使用各自的命令。 [智能体接入与返回格式](agent-integration.md)

## 3. 三种新镜头生成方式

| 方式 | 当前开源版的入口 | 谁提供算力与费用 |
| --- | --- | --- |
| 自带 Seedance API 密钥 | 内置 `seedance_http.py` 可校验、提交、查询、下载 | 火山方舟生成，使用用户自己账户的额度 |
| 本地 ComfyUI | 单独运行 ComfyUI，生成后把文件纳入影序工程 | 运行 ComfyUI 的设备提供算力 |
| 影序托管生成 | 规划中的服务接入，当前开源版通过文件接收外部结果 | 拟由影序平台分配额度，并结算上游用量 |

### 3.1 自带 Seedance API 密钥

1. 登录火山方舟，在北京区的同一资源项目开通可用的 Seedance 模型或推理接入点，记下模型 ID 或接入点 ID。在该项目创建有模型访问权限的 API Key，先核对账户额度、计费和所选规格。 [方舟密钥管理](https://docs.volcengine.com/docs/ark/manage-api-keys?lang=zh) · [视频生成参数](https://console.volcengine.com/ark/region%3Acn-beijing/docs/create-video-generation-task-api)
2. 在工程中建立 `request.json`，把下方的 `REPLACE_WITH_MODEL_ID` 换成实际 ID。另用仓库外、仅自己可访问的纯文本文件保存 API Key，一行一个值。请求文件只写模型和提示词，`--key-file` 填密钥文件的路径。

```json
{
  "model": "REPLACE_WITH_MODEL_ID",
  "content": [{"type": "text", "text": "晨雾从山谷缓慢升起，镜头平稳向前移动，最后停在山脊，固定光线，无文字。"}],
  "ratio": "16:9",
  "duration": 5,
  "resolution": "720p",
  "watermark": true,
  "generate_audio": false
}
```

3. 先校验。把下面的 `PROJECT` 和 `SECRETS` 换成已建好的实际目录。命令在 `skills/science-achievement-film` 下运行，Windows 将 `python3` 改成 `py -3` 或 `python`。校验只检查结构并返回请求指纹，账户权限、余额和模型支持规格以服务商为准。

```text
python3 references/integrations/seedance_http.py validate --request "PROJECT/request.json"
```

4. 确认提示词传输和本次费用后，使用一个全新的任务日志提交。然后查询同一个日志，状态为 `succeeded` 后下载到新文件。三个命令按顺序执行，查询未完成时稍后再查。

```text
python3 references/integrations/seedance_http.py submit --request "PROJECT/request.json" --journal "PROJECT/seedance-shot-01.json" --key-file "SECRETS/seedance-key.txt" --base-url "https://ark.cn-beijing.volces.com/api/v3" --allow-billable
python3 references/integrations/seedance_http.py query --journal "PROJECT/seedance-shot-01.json" --key-file "SECRETS/seedance-key.txt" --base-url "https://ark.cn-beijing.volces.com/api/v3"
python3 references/integrations/seedance_http.py query --journal "PROJECT/seedance-shot-01.json" --key-file "SECRETS/seedance-key.txt" --base-url "https://ark.cn-beijing.volces.com/api/v3" --download "PROJECT/shot-01.mp4"
```

提交超时或日志为 `unknown` 时，先在方舟查原任务再处理。当前客户端固定使用官方北京区接口。图像、视频或音频作为生成参考时，外部服务会接收相应输入。参考格式、任务恢复与下载规则见 [Seedance 集成说明](../skills/science-achievement-film/references/integrations/seedance.md)。

### 3.2 本机 ComfyUI 生成后导入

1. 按 [Windows、Linux、macOS 安装指南](https://docs.comfy.org/installation/manual_install) 安装 ComfyUI。按设备配置选对应的推理后端。影序只需要最后的视频文件，因此也可以在另一台更适合运行模型的电脑上生成。
2. 在 ComfyUI 里加载原生文生视频模板，例如 Wan2.2 TI2V 5B。按模板安装扩散模型、文本编码器和 VAE。手动安装时分别放入 ComfyUI 的 `models/diffusion_models`、`models/text_encoders`、`models/vae`，并在加载节点里选择对应文件。 [工作流和模型文件](https://docs.comfy.org/tutorials/video/wan/wan2_2)
3. 填写提示词，先按模板支持的较短时长和较低分辨率测试，运行后保存 MP4。把视频复制到影序工程的 `media` 目录，填写 `shots.json` 的源文件和句子对应，生成素材墙后播放审核。最后在 `edit.json` 中选择通过审核的镜头。 [镜头模板](../skills/science-achievement-film/assets/shots.example.json) · [素材墙工作流](../skills/science-achievement-film/references/quickstart.md#2-盘点理解并审核画面)

ComfyUI 的模型、端口和推理选项在 ComfyUI 自己的界面配置。开源 `v1.1.0` 通过视频文件交接。

### 3.3 影序托管生成（规划）

开源 `v1.1.0` 目前可以导入其他平台已生成的视频。影序统一账号、额度和服务端生成尚未上线。以下是将来运营方接入自有平台需要配置的内容：

1. 部署影序服务的 HTTPS 地址、用户认证、任务数据库和结果存储。给每个用户发放独立的访问凭据。
2. 在平台的密钥管理中配置上游模型服务账户，设定允许的地区、模型、规格和预算。生成任务由平台提交，上游密钥保存在服务端。
3. 平台按用户和套餐管理用量。购买成功后发放权益，提交前预留额度，用同一个任务 ID 对账、结算并提供结果下载。
4. 开源客户端可在未来通过单独的适配器连接服务，用户在本机配置影序服务地址和自己的访问凭据。拿到视频后沿用同一套素材审核和剪辑流程。

## 4. 生成后的检查

将三种方式得到的候选统一放到项目素材目录。运行媒体探测，确认编码、尺寸与时长。播放检查画面、声音和完整性，然后在素材墙记录用途、来源和审核结论。素材纳入剪辑后，按实际成片进行技术检查与归档。 [媒体工具与验收边界](../skills/science-achievement-film/references/local-media-tools.md)
